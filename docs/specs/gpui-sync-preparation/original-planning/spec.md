## Problem and Goal

Establish an upstream-rooted GPUI migration line and preserve MOLFAR's real product behavior through native services and views, using upstream equivalents rather than blindly porting React. Produce an auditable inventory and independently verifiable batches before feature implementation.

## Scope and status vocabulary

- **Shipped:** code on pinned MOLFAR main; not a new runtime-verification claim.
- **Pending remote:** open PR119 or PR117 code, not on main.
- **Pending local:** six hardening commits ahead of remote PR119, and existing uncommitted backup-worktree changes. Do not push, resume or treat them as merged.
- **Common native:** upstream already implements a capability; migrate MOLFAR-specific data/policy and validate parity rather than create duplicate functionality.
- **Backlog:** not existing behavior. Requires a separate approved feature plan.

`inventory.json` is the complete structured feature register; each M01–M22 record contains source evidence, native equivalent, unique delta, portability, dependencies, risks, proposed improvement, observable acceptance, priority, order and expected native owner paths. The full report reproduces these records for review.

## Data and functional parity

Use synthetic or explicitly copied consistent database snapshots with SQLite sidecars handled correctly; never attach native to a live production database. Export copied web-storage settings into a manifest. Keep source IDs, imported-ID mapping, content kinds, custom session metadata, Board run receipts/gates/artifact versions and Familiar file hashes explicit. Run import twice without duplication. Reopen after interrupted migration and preserve unsupported fields/settings in an import report rather than silently discard them. Initial imports keep habits, automations, provider warm starts, phone and remote listeners disabled.

Functional parity is semantic: native controls/layouts may differ, but existing user decisions, source context, stop/approval boundaries and durable outcomes must remain equivalent. A native text fallback for HTML is a known gap, not accepted parity.
